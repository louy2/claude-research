# Simplified Chinese (zh-CN) translation catalog for the Fossil web UI.
#
# Format:  a "msgid" line holds the text exactly as it appears in the Fossil
# source code, and the "msgstr" line that follows holds its translation.
# Whitespace is normalized before lookup, so a phrase that the source wraps
# over several lines is written here on one line.  An empty msgstr means
# "not translated yet" and leaves the English text in place.
#
# Markers such as <1>...</1> stand for inline markup (<a>, <b>, <code>, ...)
# in the original text; keep them in the translation and move them wherever
# Chinese word order requires.  printf() conversions such as %s and %d must
# appear in the translation in the same order as in the msgid.
#
# HTML entities (&nbsp;, &amp;, ...) are literal text here.  A translation is
# free to drop them: the whole text node is replaced, not patched.
#
# Set FOSSIL_LOCALE_TRACE=1 on a server to have every phrase that has no
# translation printed on stderr in this format.
#
# Run "fossil test-locale check zh-CN" after editing.
